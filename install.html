Setup guide

Get Viora running.

First extract the ZIP. Then load the extracted extension folder in your browser.

Choose your browser

Download the ZIP

Click Download Viora 7.24.4 above. Your browser will save viora-extension-7_24_4.zip, usually in Downloads.

Extract the ZIP file

In Windows File Explorer, right-click the ZIP and choose Extract All…, then click Extract. On macOS, double-click the ZIP. On Linux, use your archive manager’s Extract option.

Open Chrome Extensions

Enter chrome://extensions/ in Chrome’s address bar and press Enter.

Turn on Developer mode

Enable the Developer mode switch near the top-right of the Extensions page.

Load the unpacked folder

Click Load unpacked and select the extracted viora-extension-7_24_4 folder — the folder that directly contains manifest.json. Do not select the ZIP itself or its parent Downloads folder.

Pin Viora

Click Chrome’s puzzle-piece Extensions icon, find Viora, and click the pin icon. Select the Viora icon whenever you want to open the side panel. Shortcut: Ctrl + Shift + Y.

Inside Viora

How the AI works.

Viora is a browser extension that routes your request to a specialist workflow, then displays the response in its side panel. The exact response quality and available capabilities depend on the model and services reachable from your device.

01 · EVERYDAY

Viora Flash

General-purpose chat for everyday questions. It can choose a model path suited to the request and use conversation context to produce a response.

02 · RESEARCH

Deep Search

Uses the web-search and citation workflow to gather source material and present a research-style answer with references when available.

03 · PRECISION

Math & Code

Focuses on explaining calculations, working through maths problems, writing code, and helping diagnose programming errors.

04 · WRITING

Humanizer

Rewrites text to sound more natural while aiming to preserve the original meaning, facts, and writing intent.

05 · FILES

Images, documents & video

The extension includes attachment handling for images and documents and can sample frames from supported video files. What can be analysed depends on the chosen assistant and the model’s actual input support; video audio is not analysed by the frame-sampling path.

How a response is generated: you enter a prompt (and optionally page context or an attachment), Viora prepares the request for the selected assistant, contacts its configured AI/web services, then renders the reply. Internet access and provider availability are required for cloud-model responses. AI can make mistakes, so verify important answers and review actions before confirming them.
Troubleshooting

Something not working?

Chrome or Edge says “manifest file is missing”

You selected the wrong folder. Extract the ZIP, open the extracted folder, and select the folder that directly contains manifest.json. Do not select the ZIP or the outer folder.

“Load unpacked” is missing

Open the browser’s extensions page and enable Developer mode. If the browser is managed by an organization, its administrator may have disabled developer extensions.

Viora does not appear on the toolbar

Open the Extensions menu, find Viora, and pin it. Then click its icon. You can also use Ctrl + Shift + Y.

The AI cannot connect or returns an error

Check your internet connection and whether your network blocks the AI provider. Try again later if the service is unavailable. A browser extension cannot override school, workplace, or network administrator restrictions.

I moved or deleted the extracted folder

Keep the extracted extension folder in a permanent location. If you move or delete it, the browser may disable the extension; restore the folder and load it again from the extensions page.

Viora is installed as an unpacked extension in this guide. Browser menus may change slightly between versions.
