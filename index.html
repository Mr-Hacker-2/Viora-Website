How it works

From install to answer in under a minute

Add it to your browser

Install the extension. There's nothing to configure and no key to paste.

Open the panel

Click the Viora icon or press Ctrl Shift Y. It slides in beside whatever you're reading.

Ask, search, automate

Choose an assistant, type or talk, and let it work. Sign in later if you want backup.

You stay in control

Powerful, but never reckless

Automate can click and type, so it's built to ask first and to prove that things actually worked.

  • Risky clicks need your OK. Buying, sending, deleting or logging out always asks first.
  • Steps are verified. Viora reads fields back and compares the page before and after.
  • Page text can't give orders. Instructions hidden in a website are marked untrusted and refused.
  • Linux is opt-in. Shell commands stay off until you switch them on.

FAQ

Quick answers

Is Viora really free?
Yes. There's no API key to find or pay for. Install it and start chatting.
Which browsers does it work in?
Chrome 116 or newer, plus other Chromium browsers that support extension side panels.
Do I need an account?
No. An account is only for cloud backup and syncing across devices. Create one any time.
Where is my data stored?
Chats, memory and agents are stored on your device. Your messages are sent to the AI model to get an answer. Read the privacy page for details.
