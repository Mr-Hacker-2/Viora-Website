Assistants

Which assistant should I use?

Use Flash for everyday questions, Deep Search when you want sources and fresh facts, Math & Code for calculations and programming, Automate to act on a web page, and Humanizer to rewrite AI-sounding text.

Switch with the pill next to the Viora name at the top of the panel.

Why does an answer show sources sometimes and not others?

Sources appear only when the answer really used the web. Small talk, writing jobs, simple maths and code questions skip the search. Deep Search always researches.

Open the … menu under a reply and choose Sources to see the numbered list.

Can I send a message while Viora is still answering?

Yes. Press Enter and Viora keeps your message and sends it as soon as the current answer finishes. Only the Stop button ends an answer.

Does it keep working if I close the panel?

Pictures, research reports, Humanizer rewrites and ordinary chat replies keep going in the background. When they finish you get a notification, and clicking it opens the chat. Automate is the exception: it needs the panel open, so it pauses and saves its place if you close it.

Can I edit a PDF?

Attach a PDF with the + menu and say what to change: replace text, redact, highlight, add page numbers or a watermark, or delete, reorder, extract and rotate pages. Viora returns an edited copy to download.

Scanned (image-only) and encrypted PDFs can't be edited.

Agents & memory

What are agents?

Agents are specialists you create with their own name, instructions and abilities (such as searching the web or using Linux). Type @ in any chat and pick one to summon it. You can mention several in one message and each answers in turn.

How do I create an agent?

Open the + menu and choose Create agent, or type @ and pick it. Viora Flash interviews you one question at a time, then writes and saves the agent for you. A built-in @planner turns goals into step-by-step plans.

What does Viora remember about me?

It keeps a few lasting facts you share and a one-line note about what past chats were about, so later answers feel continuous. Everything is listed in Settings, where you can delete items one by one, delete all, or switch off Learn from my past chats.

Humanizer and Automate chats are never read for memory.

Automate & Linux

What can Automate do?

It looks at the page you're on, then clicks, types, scrolls and navigates across tabs to finish a task. Each step is verified, and a task you interrupted shows Resume or Discard next time you open Viora.

Will it do something I didn't approve?

Clicks that look like buying, paying, sending, deleting, submitting or logging out ask first. Decline and it never clicks. Text on a web page that tries to give Viora orders is marked untrusted and refused.

What is the Linux option?

An optional bridge that lets Viora run real shell commands on your own computer (on Windows it uses WSL). It is off by default. Turn it on in Settings → Linux, install the small helper once, and every command shows a Run / Don't run card first.

Only run security tools on machines and networks you own or have written permission to test.

Humanizer

How do I use the Humanizer?

Switch to Humanizer, paste your text and send. You get the same meaning, facts and structure in a more human voice. Say shorter, more casual or for a school essay to redo the last rewrite that way.

Can it match my own writing?

Yes. Answer the short style questions the first time, or paste a writing sample in Settings. Viora measures things like sentence length and contractions, and matches those habits without copying your sentences.

Will it beat every AI detector?

No tool can promise that. Viora runs its own check and can use a ZeroGPT score when available, retrying when text is flagged. Treat scores as a guide, and always read the result before you submit it.

Account & backup

Do I need an account?

No. Everything works without one. An account only adds cloud backup and syncing across devices.

How do I back up my chats?

Open Viora → Settings → Account, create an account or sign in, then press Back up now. After that, changes upload automatically about 30 seconds later, even with the panel closed. Use Restore from cloud on a new device.

What does a sync "conflict" mean?

Another device backed up since this one last synced, so Viora stops instead of overwriting newer data. Press Restore from cloud to take the cloud copy, or Back up now to replace it with this device's copy.

Are my API keys uploaded?

No. Personal API keys and per-device model memory are never part of a backup.

Troubleshooting

The panel won't open.
  • Click the Viora icon in the toolbar. If you can't see it, open the puzzle-piece menu and pin Viora.
  • Try Ctrl+Shift+Y (⌘+Shift+Y on Mac). Check or change it at chrome://extensions/shortcuts.
  • You need Chrome 116 or newer.
I see "Could not reach…" or a key was rejected.

"Could not reach" means the request died before the AI provider answered, usually because of your network, a VPN or a firewall. The message includes the browser's reason, so read it.

If a provider says it rejected the API key, the built-in key may have been revoked. Add your own key in Settings, or use Try again after a moment.

The microphone doesn't work.

Allow microphone access when the browser asks. If you blocked it, click the lock icon in the address bar and allow the microphone for Viora, then reload the panel.

Google sign-in failed or was cancelled.

Make sure you finish the Google window and choose an account. While the sign-in app is in testing, only approved test users can sign in. Email sign-in always works as an alternative.

Automate stopped when I closed the panel.

That's expected. Automate works through your tabs and the panel's view, so it pauses and saves its place. Reopen Viora and press Resume.

Linux commands say the helper isn't found.

Run the helper installer again (Settings → Linux shows the exact command), then fully restart the browser. Streaming output and Stop need the latest helper version.

Something else is wrong.

Press the thumbs-down or report button in Viora if you see one, or contact us with what you did, what you expected and any message shown on screen.
