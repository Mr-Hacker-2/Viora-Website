High-risk storage operation

Permanent deletion

Delete All Info from Blackblaze permanently removes all versions and delete markers in the four explicitly deletable Viora application namespaces: Planner data, Planner attachments, Personal Intelligence, and Labs CMS content/media.

Protected and preserved: user accounts and authentication records (users/), account-deletion tombstones (deleted/), administrator audit records (admin/audit/), and any unclassified or unrelated bucket objects. This action does not delete Render databases or external provider data.

A live inventory preview is required first. You must type the exact confirmation phrase and check a separate second-confirmation box. No bulk deletion runs during development or deployment.
