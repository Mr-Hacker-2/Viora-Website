Viora in your pocket

Your AI workspace. One tap away.

Install the Viora website on your phone's Home Screen so it opens like an app. This is the website—not the Chrome/Edge browser extension. Chat, web search and account features still need an internet connection.

Open Viora AI
If your browser doesn't show an install prompt, use the instructions below.
1

Android (Chrome)

Open this page in Chrome, tap the three-dot menu, then choose Install app or Add to Home screen. Confirm the prompt.

2

iPhone or iPad (Safari)

Open this page in Safari, tap Share, scroll and choose Add to Home Screen, then tap Add.

3

Launch it

Tap the new Viora icon on your Home Screen. Sign in if asked. You can also open Viora directly from the button above.

4

Not the extension

This installs a shortcut/web app for the Viora website. It does not install a browser extension and does not make the AI work offline.
